# Flask Notes App 📝

A simple web application to take personal notes, built with **Python (Flask)**, **HTML**, and **CSS**.  
Users can add notes and view them instantly.  

## Features
- Add notes  
- View saved notes  
- Delete saved notes  
- Simple user interface
